## Final project
**[Difference Mapping Social Vulnerability across Census Units in Colorado](Final%20Project/)**
A SoVI-based social vulnerability index built at block group, tract, and county
scales, with difference maps showing how a place's rank changes with the unit.
The project README describes the workflow, how to run it, and the author.
